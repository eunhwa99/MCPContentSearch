## Architecture / ADR Constraints

- ADR 0001: keep tool formatting in `api`, retrieval logic in `search`.
- ADR 0002: SQLite remains the citation/lifecycle truth; explainability must not bypass active chunk gating.
- ADR 0006: stay in slim MCP core; do not add removed product surfaces. Optional query rewrite remains config-gated and egress-limited.

## Risks and Rollback Notes

- Risk: tool contract drift if debug data leaks into default payloads.
  - Mitigation: gate with optional parameter and preserve default shape in tests.
- Risk: explain payload leaks secrets or local paths.
  - Mitigation: add redaction assertions in search/answer/API tests.
- Risk: over-explaining internal ranking data makes output noisy or unstable.
  - Mitigation: keep payload structured, reviewer-readable, and limited to safe summaries.
- Rollback point: revert the phase2 branch or drop the new optional debug parameters/tool exposure without touching storage/indexing state.
