## Architecture and ADR constraints

- Follow `.agents/docs/architecture.md` retained slim MCP boundaries.
- Stay inside ADR 0006 slim MCP core scope.
- Preserve `search_context` retained tool semantics; additive debug metadata is
  acceptable, but do not expose secrets or raw unsafe prompt content.
- Do not add code paths that inspect or mutate user SQLite/Chroma outside the
  existing retrieval/search flow.

## Risks and rollback notes

- Risk: new debug fields could drift from actual rewrite behavior.
  Mitigation: compute the decision once in the retrieval pipeline and expose the
  same payload through `ContextSearchService`.
- Risk: live smoke script could accidentally print sensitive config.
  Mitigation: only print public summary fields and reuse existing debug-redacted
  payloads instead of raw environment/config values.
- Rollback point: revert the additive debug fields and script/tests/docs from
  this branch only; no persisted data migration is involved.
