# Demo Flow

The local demo runs a short workflow smoke for users:

1. sync a bounded local Obsidian sample vault
2. run a search query against indexed notes
3. ask a grounded question
4. inspect the returned citations

This makes the retained tool-handler and service flow easy to verify in a few
minutes.
This demo exercises the retained tool-handler and service flow without needing
an external MCP client.
